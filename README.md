# Penguin Fashion 🐧

A responsive fashion landing page built using HTML and Tailwind CSS while learning frontend development.

## 🚀 Live Demo
https://stsumu.github.io/Penguin-fashion-tailwind/

## 🌟 Features
- Responsive landing page design
- Hero section with call-to-action
- Product cards (Women & Men jackets)
- Extra feature/info section
- Mobile-friendly layout

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Google Fonts

## 🎨 Design
Built by following a Figma design from a course:
https://www.figma.com/proto/dpLHx7jbTO0r3Whwse8M1P/penguin-fashion?node-id=1-7


## 📌 Note
This is a learning project built while practicing Tailwind CSS and responsive layouts.

## 🎨 How I Used Tailwind CSS
In this project, I used **Tailwind CSS via CDN** to quickly prototype the UI without a build process.

Added this inside the `<head>`:

```html
<script src="https://cdn.tailwindcss.com"></script>
