# Penguin Fashion 🐧

A responsive fashion landing page built using HTML and Tailwind CSS while learning frontend development.

## 🌟 Features
- Responsive landing page design
- Hero section with call-to-action
- Product cards (Women & Men jackets)
- Extra feature/info section
- Mobile-friendly layout

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Google Fonts
